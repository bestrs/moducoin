## 프로젝트 소개

Moducoin 저장소에는 CryptoNote 계열 코드베이스와 프로젝트 관련 기록이 담겨 있습니다. CryptoNote는 이 코드가 바탕으로 삼은 기술 계열을 설명하는 말이며, 이 저장소만으로 현재 네트워크가 운영 중인지 또는 코인을 거래할 수 있는지는 확인할 수 없습니다.

> **현재 상태 확인 필요**<br />
> 저장소의 프로젝트 소개는 2018년에 마지막으로 수정되었습니다. 네트워크, 지갑, 채굴, 배포 및 운영 상태는 최신 정보로 확인되지 않았습니다. 이 README는 역사적 기록과 현재 확인 가능한 저장소 내용을 구분합니다.

## 저장소 둘러보기

| 경로 | 내용 |
| --- | --- |
| `src/` | 노드 및 응용 프로그램 소스 코드 |
| `include/` | 공개 헤더 |
| `tests/` | 테스트 코드 |
| `external/` | 외부 라이브러리 및 관련 코드 |

| `CMakeLists.txt` | CMake 빌드 설정 |

## 기술 정보

- **언어:** C와 C++ (C++11 설정 포함)
- **빌드 시스템:** CMake
- **코드 계열:** CryptoNote 기반

이 정보는 저장소의 빌드 설정과 기존 기록을 바탕으로 정리했습니다. 현재 운영체제에서의 빌드 성공 여부나 최신 의존성 호환성은 검증되지 않았습니다.

## 기록과 주의사항

저장소에 남아 있는 초기 소개에는 과거 계획과 경제적 가치에 관한 설명이 포함되어 있었습니다. 해당 문구는 현재의 운영 사실이나 투자 성과를 증명하지 않으므로 이 README에서는 현재 약속처럼 재인용하지 않습니다. 프로젝트의 공식 공지나 최신 운영 현황이 확인되면 이 섹션과 문서를 갱신해 주세요.

## 기여

수정 제안은 GitHub **Pull Request(PR)** 로 보내 주세요. PR은 변경 내용을 비교하고 검토한 뒤 저장소에 반영할지 결정하는 제안입니다. 작은 변경부터 시작해도 좋습니다.

1. 저장소를 포크하거나 작업 브랜치를 만듭니다.
2. 변경 사항과 확인 방법을 설명에 적습니다.
3. PR을 열어 변경 내용을 검토받습니다.
